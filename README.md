# student-marks-prediction-system

## Overview

This project is a Machine Learning based web application developed using Flask and Scikit-learn.

The system predicts student marks using the Multiple Linear Regression algorithm based on:

- Study Hours
- Sleep Hours
- Attendance Percentage

The application also analyzes student performance and displays the prediction result through a user-friendly interface.


## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- HTML/CSS
